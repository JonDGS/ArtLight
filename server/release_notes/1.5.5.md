# ArtLight 1.5.5 - 2026-10-13

Developed by onaiaku & Rias.

## Added

- **Ticking a permission box in the Web UI saves it straight away.** Changing a client's View or Launch permission used to mean finding the Save button at the bottom of the form; a single on/off setting now saves the moment you tick it. The rest of that form still uses Save and Cancel together.

## Fixed

- **Control's Sessions page no longer fails and no longer takes your saved clients with it.** A machine with two games installed under the same name made Control fail while it drew the session list, and the failure left nothing behind to explain it. Call of Duty ships separately from both Xbox and Steam, so this was easy to hit. Repeated names are handled now, and the session list opens normally.
- **Control leaves a log behind if it ever goes down again.** A crash used to close the app with no record anywhere, so there was nothing to send with a report.
- **Your desktop wallpaper is no longer recorded as the game you played.** Wallpaper Engine runs the whole time a desktop stream is open, and it was being credited as the game that was played - in the session list, on the last-stream card and on your phone. It is not tracked as a game at all now, and sessions that already named it have been corrected to show no game detected.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
