# ArtLight 1.5.4 - 2026-10-11

Developed by onaiaku & Rias.

## Fixed

- **A second device now really does see what the host is streaming.** 1.5.3 promised this and did not deliver it: opening ArtMoon on another device while a host was streaming Desktop still showed that machine as free, with no STREAMING badge and no Resume or Stop. Any device allowed to view a host is now told what that host is doing, and shows the running stream with its Resume and Stop buttons.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
